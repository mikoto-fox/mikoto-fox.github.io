# 日々の余白 — MY PERSONAL PAGE

和紙色・墨色・藍色を基調にした、シンプルな個人プロフィールサイトです。
HTML/CSSのみで構成し、GitHub Pagesで公開できます。

## 編集する場所

- `index.html`
  - 自己紹介文
  - 趣味の説明
  - Xのリンク（`https://x.com/your_account` と `@your_account` を変更）
  - ページタイトルや説明文
- `css/style.css`
  - 色、余白、文字サイズ、レイアウト

## GitHub Pagesで公開

1. GitHubで `username.github.io` という名前の公開リポジトリを作成
2. このフォルダ内の `index.html` と `css/` をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択して保存
4. 数分後、`https://username.github.io/` で公開

## 注意

- Xのリンクは必ず自分のアカウントURLに変更してください。
- GitHub Pagesの公開リポジトリではソースコードも公開されます。住所・電話番号などの個人情報は載せないでください。
- Google Fontsを利用しています。外部通信を避けたい場合はCSSのフォント指定を変更してください。
